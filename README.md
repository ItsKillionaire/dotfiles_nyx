## Keybindings

### Application Launchers
| Keybinding | Action |
| --- | --- |
| `Super + Q` | Open Terminal (Ghostty) |
| `Super + F` | Open File Manager (Thunar) |
| `Super + B` | Open Web Browser |
| `Super + Space` | Open Application Menu (Wofi) |
| `Super + N` | Toggle Notification Center |

### Session & Window Management
| Keybinding | Action |
| --- | --- |
| `Super + Shift + Ctrl + M` | Exit Hyprland Session |
| `Super + Escape` | Close Active Window |
| `Super + E` | Toggle Floating Window |
| `Super + R` | Toggle Pseudotile |
| `Super + J` | Toggle Split Direction |
| `Super + W` | Toggle Fullscreen |
| `Super + L` | Lock Screen |
| `Super + Shift + L` | Suspend System (Sleep) |

### Focus & Movement
| Keybinding | Action |
| --- | --- |
| `Super + Arrow Keys` | Change Focus |
| `Super + Alt + Arrow Keys` | Move Active Window |
| `Super + Ctrl + Arrow Keys` | Resize Active Window (Slow) |
| `Super + Shift + Ctrl + Arrow Keys`| Resize Active Window (Fast) |

### Workspace Control
| Keybinding | Action |
| --- | --- |
| `Super + [0-9]` | Switch to Workspace 1-10 |
| `Super + Shift + [0-9]`| Move Window to Workspace 1-10 |
| `Super + Mouse Wheel` | Switch to Next/Previous Workspace |
| `Super + S` | Toggle Special Workspace (Scratchpad) |
| `Super + Shift + S` | Move Window to Special Workspace |

### Utilities
| Keybinding | Action |
| --- | --- |
| `Super + F9` | Cycle Audio Output |
| `Super + V` | Show Clipboard History (Wofi) |

### Screenshots
| Keybinding | Action |
| --- | --- |
| `PrintScreen` | Screenshot a Region |
| `Shift + PrintScreen` | Screenshot an Entire Monitor |
| `Ctrl + PrintScreen` | Screenshot the Active Window |
| `Alt + PrintScreen` | Screenshot with OCR (Text Recognition) |
